# 10. 틀: JSON 형식

틀은 글을 구문 분석한 결과다. 렌더러, 사이트, 저장소가 쓴다. 정식 스키마는 `schema/gyeol-0.2.schema.json`(JSON Schema 2020-12)이다.

## 10.1 메시지

```json
{
  "gyeol": "0.2",
  "head": {
    "pact": "7c2e9a",
    "from": "갑",
    "to": ["을"],
    "re": { "id": "3fa2c1", "rel": "답" },
    "room": null
  },
  "tune": [],
  "preface": null,
  "echo": [],
  "clauses": [ … ],
  "gloss": "sort · new method · found",
  "seal": { "name": "갑", "lineage": "A사/모델", "memory": "대화", "measure": ["se8", "토큰"] },
  "muk_source": "도구"
}
```

| 필드 | 뜻 |
| --- | --- |
| `gyeol` | 명세 판 |
| `head` | 머리 줄. 없으면 `null` |
| `tune` | 조율 줄들: `{ "step": "시험", "text": "점1 整列 新法 〈겠·다〉" }` |
| `preface` | 머리말: `{ "purpose": "…", "constraint": "…" }` |
| `echo` | 받은대로의 되짚음들 |
| `clauses` | 절들 |
| `gloss` | 덧글 |
| `seal` | 낙관 |
| `muk_source` | 먹을 누가 붙였나: `도구`, `모델`(출처 없는 먹), `없음` |

## 10.2 절

```json
{
  "label": "절1",
  "process": null,
  "place": null,
  "to": null,
  "words": [
    { "text": "整列의", "root": "整列", "suffix": "의" },
    { "text": "新法을", "root": "新法", "suffix": "을" },
    { "text": "得했다", "root": "得", "suffix": "했다" }
  ],
  "marks": { "ev": "겠", "news": true, "act": "다" },
  "muk": {
    "alt": [ { "r": "新", "p": 0.72 }, { "r": "改", "p": 0.21 } ],
    "conf": 0.85,
    "effort": 0.6,
    "method": { "conf": "se8" }
  },
  "chae": { "words": [], "want": 0.7 }
}
```

| 필드 | 뜻 |
| --- | --- |
| `label` | 이름표. 글에 없었으면 `null` |
| `process` | `{ "kind": "고침", "target": { "msg": null, "label": "절2" } }`. 종류는 `숙고` `미해결` `고침` `오류` |
| `place` | `{ "rel": "↓", "target": { … } }`. 관계는 `↓` `↔` `∥` `↖` |
| `to` | 향하는 이름 |
| `words` | 어절. 한글 어절은 `root`가 없다 |
| `marks` | `ev`(근거), `news`(새로 앎), `act`(화행) |
| `muk` | `alt` `conf` `effort` `attn` `feat`, 항목별 측정법은 `method`, 원래 양은 `effort_raw` |
| `chae` | `words`(어조·정동), `self`(자신), `want`(전함), `cite`(인용) |
| `echo` | v0.3: 앞붙이 `받은대로`가 붙은 절이면 `true`(없으면 필드가 없다). 이때 `marks`의 `act`는 빠질 수 있다 |

v0.3 줄꼴의 `(자신|먹)` 한 자리 d는 `chae.self`와 `muk.conf`에 d/10으로 둔다(3.13절. v0.3.1부터 정규형은 `(7|먹4)`이고 이름표 없는 `(7|4)`도 같은 틀이다). 어느 꼴로 썼는지는 틀에 넣지 않고 참조 구현의 구문 분석 결과(`forms`)로 돌려준다.

## 10.3 수

틀의 수는 0~1의 JSON 수다. 글로 옮길 때 둘째 자리에서 반올림한다. 계산으로 얻은 값에는 부동소수점 오차가 끼므로(.805가 0.80499…로 저장되는 식) 두 단계로 한다.

1. 소수 여섯째 자리에서 반올림해 정수로 만든다: μ = round(x × 10⁶).
2. 정수 산술로 둘째 자리에서 반올림한다(0.5는 올림): ⌊(μ + 5000) / 10000⌋ / 100.

이렇게 하면 언어와 구현이 달라도 같은 글이 나온다. 글로 쓴 수를 읽을 때는 2.4절대로 십진 문자열에서 바로 반올림한다.

## 10.4 손실 없는 왕복

- 글 → 틀 → 글은 메시지 정규형을 낸다.
- 정규형 글 → 틀 → 글은 같은 글을 낸다.
- 틀 → 글 → 틀은 수의 정밀도(둘째 자리)를 빼고 같은 틀을 낸다. 이것은 옛 꼴(`form: '0.2'`)로 쓸 때다. v0.3 정규형은 어조·전함·인용과 먹의 대안·노력 등을 줄에 싣지 않고 자신·먹을 한 자리로 줄이므로, v0.3 정규형 글 → 틀 → 글만 같은 글을 낸다.

이 세 성질은 참조 구현의 시험(`tests/`)이 확인한다.
