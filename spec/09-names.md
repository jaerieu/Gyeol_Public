# 9. 이름, 판, 해시

## 9.1 두 가지 이름

결의 모든 것은 두 이름을 가질 수 있다.

| 이름 | 무엇 | 정하는 법 | 바뀌나 |
| --- | --- | --- | --- |
| 먹 이름 | 내용의 해시 | 계산한다 | 내용이 바뀌면 바뀐다 |
| 채 이름 | 사람과 모델이 부르는 이름 | 고른다 | 고를 수 있다 |

언어 자체의 정체는 먹 이름이다. 채 이름 '결'을 바꿔도 기본 사전과 명세가 같으면 같은 언어다(초안 13장 8번).

## 9.2 먹 이름 계산

- 사전, 짝 약속, 정답 글처럼 결 문법으로 읽지 않는 글: 문서 정규화(2.3절) 후 UTF-8 바이트의 SHA-256.
- 결 메시지: 메시지 정규형(3.9절)의 UTF-8 바이트의 SHA-256.
- 적을 때는 `#` 뒤에 16진수 앞 여섯 자리를 쓴다: `#8811fa`. 같은 방이나 저장소 안에서 여섯 자리가 겹치면 겹치지 않을 때까지 늘린다. 전체는 64자리다.
- 문서는 맨 끝에 `맞춤값: n` 줄을 더해 원하는 앞자리를 찾을 수 있다. 이 줄도 해시에 들어간다. 메시지에는 쓰지 않는다.

| 대상 | 먹 이름 |
| --- | --- |
| 기본 사전 v0 (`sources/dict-v0.txt`) | `#8811fa` |
| 기본 사전 v0.2 (`dict/base-v0.2.txt`) | `#14f799` (전체는 `dict/HASHES.md`) |

v0.1 시험지의 `#1f04b3`과 `#7c2e9a`는 해시가 아니라 이름표였다(12장).

## 9.3 채 이름과 언어 번호

- 채 이름: 결. 로마자 표기 `gyeol`.
- 언어 번호: 채 이름의 코드 포인트를 소문자 16진수로 적고, 글자가 여럿이면 `-`로 잇는다. 결은 U+ACB0이므로 `acb0`이다.
- 언어 태그: BCP 47 사설 태그 `x-gyeol`. 판을 밝힐 때는 `x-gyeol-v02`.

## 9.4 판

- 명세 판은 `주.부`로 적는다(지금 0.2). 메시지 머리의 `결 0.2`가 이 판이다.
- 기본 사전은 명세 판과 같은 번호를 쓰고, 먹 이름으로 정확히 가리킨다.

## 9.5 안정성

유니코드의 이름 안정성 방침을 빌린다.

- 공개한 판에 들어간 표지, 열쇠말, 측정법 식별자의 뜻은 바꾸지 않는다.
- 잘못이 드러나면 새 이름을 더하고 옛 이름은 별칭으로 남긴다. 구문 분석기는 별칭을 계속 읽는다.
- 0.x 판에서는 아직 공개 판이 없다. 1.0부터 이 방침을 지킨다.
