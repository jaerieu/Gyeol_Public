## 표기 약속

규범어는 셋이다.

- **한다**: 지키지 않으면 결이 아니다. 검사기가 오류로 낸다.
- **하는 것이 좋다**: 지키지 않아도 결이지만, 검사기가 경고로 낸다.
- **해도 된다**: 선택이다.

근거의 성격은 초안의 꼬리표를 그대로 쓴다.

| 꼬리표 | 뜻 |
| --- | --- |
| \[근거\] | 문화를 넘는 연구가 받치는 대응 |
| \[관습\] | 특정 문화권에서 학습된 대응 |
| \[설계\] | 이 명세가 정한 선택. 실험 결과에 따라 바뀔 수 있다 |
| \[미검증\] | 출처 없는 일반화. 결론의 근거로 쓰지 않는다 |
| \[영감\] | 비유로 가져온 전통. 근거가 아니다 |

## 판 규칙

- 0.x 판 사이에는 하위 호환을 약속하지 않는다. 다만 v0.1 시험지의 표기는 v0.2에서도 모두 유효하다.
- 한 번 공개한 표지와 열쇠말의 뜻은 바꾸지 않는다. 잘못이 드러나면 새 이름을 더하고 옛 이름은 별칭으로 남긴다(9장).
