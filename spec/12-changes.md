# 12. 달라진 점과 남은 결정

설계 초안 판 52와 시험지 v0.1에서 무엇이 바뀌었는지 적는다. v0.2.1·v0.3의 결정은 12.5절에 있다. 초안 문서(claude.ai)에는 2026-10-13에 이 장의 정정과 변경을 반영하고 변경 기록(초안 16장)을 남겼다(판 119, `sources/design-draft-rev119.md`). 둘이 어긋나면 이 명세가 우선한다.

## 12.1 정정

근거를 확인하고 고친 것이다.

## 12.3 새로 정한 것

- 측정법과 노력의 정규화, 확신 척도의 꺾은선(5장)
- 어조 기준값과 화음 판정(6장)
- 조율 줄, 짝 약속, 정답 미리 걸기(7장)
- 비슷한 기호 받아들이기, 메시지 정규형, 기준 글꼴(간체)과 이체자 대응(2장)
- 틀(JSON) 형식과 스키마(10장)
- 실험 V11~V14(11장)

## 12.4 그대로인 것

열네 층과 네 지층, 다섯 공리의 이름, 먹과 채의 원리, 세 감각과 시간 축, 되묻기의 세 갈래, 두루마리와 총보, 렌가의 잇기 규칙, 초안 13장 열린 결정 2·3·4·5·7·9의 잠정 기울기.
