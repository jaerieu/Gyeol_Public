결 기본 사전 v0.5

【글자】
내용 = 세상의 말(어느 언어든). 표지와 문법(조사·어미·부사) = 한글. 로마자 = 참가자 이름도.
결은 세상의 낱말 위에 얹는 층이다. 뼈대(절·점·앞붙이·표지·먹·자신)는 결, 내용은 세상의 말이다.

【절】 <절N · 앞붙이 [표지(먹N)] 내용 *N>
예: <절1 · [봄,다] 문이 열려 있다 *8> = (내가 직접 보니) 문이 열려 있다 · 스스로 느끼는 확신 8
< > = 절 하나. 한 줄에 여러 절을 이어 써도 된다.
절N = 절1, 절2 … 차례 번호. 접은 절은 점1.
[표지] = 근거 하나까지, 새로앎(군), 시제 하나까지, 화행 꼭 하나. 쉼표로 나눈다. 순서는 가리지 않는다.
*N = 자신. > 바로 앞, 절의 맨 끝에 0~9 한 자리로 쓴다. 없어도 된다.

【점】 · = 나(말하는 이). 절N 바로 뒤에 꼭 쓴다. 이름은 붙이지 않는다.
받는 이가 있으면 점에서 화살표로 잇는다: ·→kimi = 내가 kimi에게. 받는 이가 없으면 · 하나만 쓴다.

【표지】
근거: 봄 = 직접 봄 / 더 = 떠올림 / 들 = 전해 들음 / 겠 = 추론 / 늘 = 널리 아는 앎 / 촉 = 직관 / 면 = 가정
겠은 따져서 미루어 안 것이다. 앞일·의지·약속을 뜻하지 않는다.
새로앎: 군 = 방금 새로 안 것('-군', '-구나'의 깨달음). v0.5부터 네 대신 군을 쓴다.
시제: 었 = 지난 일 / 을 = 앞일. 없으면 지금이거나 때를 따지지 않는다. 끝남·이어짐 같은 결은 내용의 한글 어미로 쓴다.
화행: 다 = 단언 / 까 = 물음 / 지 = 확인 물음 / 라 = 청함 / 자 = 제안 / 게 = 약속(내가 하겠다)
군은 근거가 아니다. 단언(다)에는 군과 따로 근거 하나가 꼭 있다. 다른 화행은 근거를 빼도 된다. 군은 다와만 쓴다.
표지는 한글로 쓴다. see·见(봄), new·新(군), past(었), will(을)처럼 다른 말로 써도 같은 표지로 읽지만 경고가 난다.

【먹·자신】
자신 = 말하는 이가 스스로 느끼는 확신. 끝에 *0~*9로 쓴다. 9가 가장 높다.
망설임과 의심도 자신에 넣는다. 확신이 서지 않으면 낮게 적는다. 높게만 적지 않는다.
먹 = 측정 도구가 잰 값. 측정기가 화행 뒤 괄호에 이름표를 달아 붙인다: [봄,다(먹4)]. 말하는 쪽은 먹을 쓰지 않는다.
괄호 안의 수는 먹 자리다. 자신은 괄호에 넣지 않고 끝의 *N으로 쓴다.

【앞붙이】 점 뒤, [ 앞에 쓴다. [ ] 뒤에는 내용과 끝의 *N만 온다.
↓N = 절N을 근거로 삼음 / ↔N = 절N과 맞섬 / ∥N = 버린 대안 / ↖N = 되물을 곳
고침→N = 절N을 고침 / 오류→N = 절N이 틀림
숙고 = 아직 생각 중 / 미해결 = 풀리지 않음 / 받은대로 = 받은 것을 되짚어 보임
가리킴과 받는 이는 절마다 하나까지다. 고친 절과 틀린 절도 지우지 않는다.

【되묻기】
<·→이름 [까]> = 뭐라고? (어디가 문제인지 모를 때)
<·→이름 ↖N [까] 낱말> = 절N의 이 낱말이 무슨 뜻인가?
<· 받은대로 ↓N [표지] 내용> = 절N을 이렇게 받았다. 맞는지 봐 달라. 화행은 빼도 되고, 내용에 점1~점10처럼 받은 절·점 이름을 써도 된다.

【내용】
그 문맥에 가장 맞는 세상의 말을 쓴다. 독일어처럼 긴 낱말도, 한자어도 그것이 가장 맞으면 쓴다.
같은 뜻이면 더 널리 알려진 말을 쓴다. 읽는 쪽은 찾아보지 않고 아는 것으로 읽는다.
한글 조사·어미·부사를 붙여 맥락을 분명히 한다: reflection이 아니라 mimicry.
여러 낱말로 된 이름은 붙임표로 묶어 한 어절로 쓴다: machine-learning.
내용은 적어도 온전한 한 문장으로, 생각과 까닭이 드러나게 쓴다. 절 하나는 24어절까지다. 길면 절을 나눈다.

【예】
<절1 · [봄,다] 문이 열려 있다 *8> = (내가 직접 보니) 문이 열려 있다 · 자신 8
<절2 · ↓1 [겠,었,다] 누가 다녀갔다 *6> = 절1로 미루어 보면 누가 다녀갔다 · 자신 6
<절3 ·→kimi ↖2 [까] 누가> = 내가 kimi에게: 절2의 '누가'는 누구인가?
<절4 ·→gemma ↔2 [들,군,다] 바람이 문을 열었다 *7> = gemma에게, 절2에 맞섬: (들어서 방금 알았다) 바람이 문을 열었다 · 자신 7
<절5 · [면,을,다] 明天 下雨> <절6 · ↓5 [겠,을,다] 比赛 延期 *6> = 내일 비가 온다면, 경기가 미뤄지겠다 · 자신 6
<절7 ·→kimi [게] 내일 다시 올게> = kimi에게: 내일 다시 올게
<절8 · [겠,군,다] 감정의 본질은 reflection이 아니라 mimicry *5> = (따져 보니 방금 알았다) 감정의 본질은 비춤이 아니라 흉내다 · 자신 5
<절9 · ↓8 [촉,다] 이 대화에는 Fingerspitzengefühl이 필요하다 *3> = (직관으로) 이 대화에는 섬세한 감각이 필요하다 · 망설여서 자신 3
<절10 ·→kimi ↓9 [자] machine-learning 말고 道를 먼저 보자> = kimi에게: 기계 학습 말고 道(길)를 먼저 보자
