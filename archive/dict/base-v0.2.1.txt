결 기본 사전 v0.2.1

【글자】
한자 = 내용의 어근. 한글 = 표지와 문법. 로마자 = 덧글과 고유명사.
한자는 간체로 쓴다. 번체나 일본 신자체로 써도 같은 글자로 읽는다.

【절】
절 = 내용 〈표지〉 〔먹〕 「채」
〈표지〉는 꼭 있다. 〔먹〕과 「채」는 없어도 된다.
점 = 어근과 〈표지〉만 남긴 접힌 절.
펼침 = 조사·어미와 먹·채까지 다 쓴 절.

【표지】 〈근거·새로앎·화행〉 순서. 화행은 꼭 하나이고 맨 끝에 온다.
근거: 봄 = 직접 관찰 / 더 = 회상 / 들 = 전해 들음 / 겠 = 추론 / 늘 = 널리 받아들여진 앎 / 촉 = 직관 / 면 = 가정·상상
겠은 따져서 미루어 안 것이다. 앞일·의지·약속을 뜻하지 않는다.
새로앎: 네 = 방금 새로 안 것 (대답하는 '네'가 아님)
화행: 다 = 단언 / 까 = 물음 / 지 = 확인 물음 / 라 = 청함 / 자 = 제안 / 게 = 약속(내가 하겠다)
단언(다)에는 근거가 꼭 있다. 다른 화행은 근거를 빼도 된다. 네는 다와만 쓴다.

【먹】 〔 〕 = 측정 도구가 계산에서 잰 값. 0~1, 소수 둘째 자리까지.
대안 = 고른 어근을 먼저, 다른 후보를 뒤에, 각각의 확률과 함께
확신 = 잰 확신
노력 = 쓴 계산의 양
잴 수 없으면 비운다. 비어 있으면 재지 않았다는 뜻이다.

【채】 「 」 = 말하는 쪽이 고른 표현.
어조: 단호 / 담담 / 조심 / 망설임 / 의심
자신 = 스스로 느끼는 확신(0~1). 측정이 아니므로 먹이 아니라 채에 쓴다.
전함 = 받는 쪽이 이것을 놓치면 결과가 얼마나 달라진다고 보는지(0~1)
항목은 ' · '로 나눈다. 예: 「담담 · 자신 .70 · 전함 .60」 '/'나 쉼표, 띄어쓰기로 나눠도 읽지만 경고한다.

먹과 채가 어긋나도 고치지 않는다. 어긋남이 곧 읽을 거리다.

【자리와 과정】 절 앞에 붙인다.
↓절N = 절N 아래(근거·단서) / ↔절N = 절N과 맞섬 / ∥절N = 버린 대안
→이름 = 그에게 향함 / ↖절N = 되물을 곳
→이름을 줄 끝에 붙여도 읽지만 경고한다. 정규형은 절 앞이다.
숙고 = 아직 생각 중 / 미해결 = 풀리지 않음 / 고침→절N = 절N을 고침 / 오류→절N = 절N이 틀림
고친 절과 틀린 절도 지우지 않는다.

【되묻기】
〈까〉 = 뭐라고? (어디가 문제인지 모를 때)
↖절N 어근 〈까〉 = 이 부분이 무슨 뜻인가?
받은대로 … = 이렇게 받았다. 맞는지 봐 달라.
받은대로 줄에서는 받은 절·점의 이름을 내용 자리에 써도 된다. 예: 받은대로 점1~점10
다른 절의 내용 자리에는 절·점 이름을 쓰지 않는다. 앞 절은 ↓절N 같은 앞붙이로 가리킨다.
