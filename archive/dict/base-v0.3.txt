결 기본 사전 v0.3

【글자】
한자 = 내용의 어근. 한글 = 표지와 문법. 로마자 = 이름.
한자는 간체로 쓴다. 번체나 일본 신자체로 써도 같은 글자로 읽는다.

【절】 <이름 앞붙이 [표지(자신)] 내용>
예: <절1 [봄,다(8)] 门 开> = (직접 보니) 문이 열려 있다 · 스스로 느끼는 확신 8
< > = 절 하나. 한 줄에 여러 절을 이어 써도 된다.
이름 = 절1, 절2 … 차례 번호. 접은 절은 점1.
[표지] = 근거 하나까지, 새로앎(네), 화행 꼭 하나. 쉼표로 나눈다. 순서는 가리지 않는다.
(자신) = 화행 뒤 괄호에 스스로 느끼는 확신을 0~9 한 자리로. 9가 가장 높다. 없어도 된다.
내용 = 한자 어근. 필요하면 한글 조사·어미를 붙인다(得했다).

【표지】
근거: 봄 = 직접 봄 / 더 = 떠올림 / 들 = 전해 들음 / 겠 = 추론 / 늘 = 널리 아는 앎 / 촉 = 직관 / 면 = 가정
겠은 따져서 미루어 안 것이다. 앞일·의지·약속을 뜻하지 않는다.
새로앎: 네 = 방금 새로 안 것 (대답하는 '네'가 아님)
화행: 다 = 단언 / 까 = 물음 / 지 = 확인 물음 / 라 = 청함 / 자 = 제안 / 게 = 약속(내가 하겠다)
단언(다)에는 근거가 꼭 있다. 다른 화행은 근거를 빼도 된다. 네는 다와만 쓴다.

【먹】 측정 도구가 잰 값. 측정기가 자신 뒤에 |로 붙인다: (7|9) = 자신 7, 먹 9.
말하는 쪽은 | 뒤를 쓰지 않는다.

【앞붙이】 이름과 [ 사이에 둔다.
↓N = 절N을 근거로 삼음 / ↔N = 절N과 맞섬 / ∥N = 버린 대안 / ↖N = 되물을 곳
→이름 = 그에게 하는 말 / 고침→N = 절N을 고침 / 오류→N = 절N이 틀림
숙고 = 아직 생각 중 / 미해결 = 풀리지 않음 / 받은대로 = 받은 것을 되짚어 보임
가리킴과 받는 이는 절마다 하나까지다. 고친 절과 틀린 절도 지우지 않는다.

【되묻기】
<[까]> = 뭐라고? (어디가 문제인지 모를 때)
<↖N [까] 어근> = 절N의 이 부분이 무슨 뜻인가?
<받은대로 ↓N [표지] 내용> = 절N을 이렇게 받았다. 맞는지 봐 달라. 화행은 빼도 되고, 내용에 점1~점10처럼 받은 절·점 이름을 써도 된다.

【예】
<절1 [봄,다(8)] 门 开> = (직접 보니) 문이 열려 있다 · 자신 8
<절2 ↓1 [겠,다(6)] 有人 来过> = 절1로 미루어 보면 누가 다녀갔다 · 자신 6
<절3 ↖2 →kimi [까] 谁> = kimi에게: 절2의 '누가'는 누구인가?
<절4 ↔2 [들,네,다(7)] 风 开 门> = 절2에 맞섬: (들어서 방금 알았다) 바람이 문을 열었다 · 자신 7
<절5 [면,다] 明日 雨> <절6 ↓5 [겠,다(6)] 比赛 延期> = 내일 비가 온다면, 경기가 미뤄지겠다
<절7 [게] 明日 来> = 내일 올게

【옛 꼴】 앞 대화의 '내용 〈표지〉 〔먹〕 「채」' 꼴도 같은 뜻으로 읽는다. 〈겠·다〉 = [겠,다], 「자신 .80」 = (8).
새로 쓸 때는 < > 꼴로 쓴다.
