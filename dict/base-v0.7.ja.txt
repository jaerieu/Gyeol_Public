Gyeol 基本辞書 v0.7（実験的, experimental）— 日本語訳（正本は英語 dict/base-v0.7.txt、正体は正本の墨の名）

【文字】
内容 = 世界の言葉（どの言語でもよい）。標識 = 英語、三文字まで（see · inf · say）。助詞・語尾・副詞 = 利用者の言語。参加者の名前はローマ字。
Gyeol は世界の言葉の上に重ねる層である。骨組み（節・点・接頭・標識・墨chae・根拠）は Gyeol、内容は世界の言葉である。骨組みがすでに言ったことは、内容で繰り返さない。
標識は英語で書くが、韓国語の 봄·겠·다、中国語・日本語の 見·推·言、ドイツ語・フランス語・イタリア語・スペイン語・ロシア語の短い形（seh·fol·sag、voi·inf·dir、ved·inf·dir、ver·inf·dic、вид·выв·утв …）も、警告なしに同じ標識として読む。正規形は英語である。長い別名（recall、assert …）は警告つきで読む。

【節】 <N 点 接頭 [標識] 内容 *chae↓根拠>
例：<1 · [see,say] the 門 is open *B8> = （直接見た）扉が開いている · 確信 8
< > = 節ひとつ。一行に複数の節を続けて書いてもよい。N = 1、2 … 節の番号で、数だけを書く。
[標識] = 証拠は一つまで、new（たった今知った）、修辞は一つまで、時制は一つまで、発話行為はちょうど一つ。コンマで区切り、この順に書く：[証拠,new,修辞,時制,行為]。順序が違っても読むが、警告が出る。
末尾の束 *chae↓根拠 は > のすぐ前に書く。chae は必ず書く。

【点】 N のすぐ後に必ず書く。
· = ひとりごと。·→名前 = 私からその人へ：·→kimi = 私から kimi へ。·→名前,名前 = 複数へ、三人まで（·→kimi,gemma）。● = みんなへ。● には宛先を置かない。

【標識】
証拠：see = 直接見た / rec = 思い出した / inf = 推論 / gut = 直感 / if = 仮定 / top = 新しい話題
inf は、筋道を立てて考えて知ったことである。未来・意志・約束を意味しない。
top = 前のどの節にも寄りかからず、新しい話題として出す言葉である。そのため top の節は他の節を指さない（↔ ↖ fix→ err→ sup→、末尾の ↓ も書かない）。土台があるなら、その土台に合う証拠を使う。
gut = 直感：理由はまだ浮かばないが、当たっていそうな感じである。錯覚かもしれず、結果だけが決める。理由を挙げられるなら gut ではなく inf に ↓根拠 をつけて書く。gut は今扱っている話についての直感であり、top は今扱っている話についてのものではない。
gut と top の節は、他の節の根拠（↓）になれない。それらに応じるときは ↔ か ↖ で指す。
新知：new = たった今知ったこと。new は証拠ではない。断言（say）には、new とは別に証拠がひとつ必ず要る（top も証拠の位置を占める）。new は say とだけ使う。
修辞：lim = 限界（この推論はここまで） / pdx = 逆説（自己矛盾を抱えたまま話す） / met = 比喩（たとえて話す）
時制：pst = 過去 / fut = 未来。なければ現在か、時を問わない。
発話行為：say = 断言 / ask = 質問 / req = 依頼 / let = 提案 / vow = 約束（私がやる） / nay = 拒否 / ack = 譲歩（相手の論点を認める）。say 以外の行為は証拠を省いてよい。

【墨 · chae · 根拠】 節の末尾の *墨chae↓根拠
chae = 話し手が書く値。色ひとつと確信 0–9 を合わせて書く：*R8。chae は必ず書く。欠けた行は誤りである。
色 = R G B C M Y K の七文字のうちひとつを、文字のまま書く（R 赤 · G 緑 · B 青 · C シアン · M マゼンタ · Y 黄 · K 黒）。色コード（#ff0000 など）でも絵文字でもない。話す内容に合うと感じる色を選ぶ。色の意味は決まっていない。受け手が知らなくてもよい。
確信 = 話し手が自分で感じる確かさ。9 が最も高い。ためらいや疑いも確信に入れる。自信がなければ低く書く。高くばかり書かない。
墨(ink) = 話し手の信用等級 0–9（9 が最も高い）。測る側が、積み重なった記録から付ける。行では * と chae のあいだが墨の位置であり（*6R8）、会話では話し手の名前の横に表示される：← kimi · ink 6。話し手は墨を書かない。誰もが真ん中の 5 から始まる：まだ何も分かっていないという意味で、記録がそこから動かしていく。
墨は、確信が結果とどれだけ合うかで付く（確信の信頼性）。分からないときは低く、分かるときは高く、当たりそうな分だけ正直に書くのが最も得になる。分からないとき、「不明」よりも、最もありそうな答えに低い確信をつけるほうがよく、chae を省くことはいつも損になる。試験のたびに古い記録は少しずつ薄れるので、最近の答えのほうが重い。確信が低いときに正直に助けを求めても、少し上がる。
墨は、その人が書いた確信をどこまで文字どおりに読むかを決める（保証）。墨 2 以下なら、その人の確信は五分五分として読み、5（まだ記録なし）なら手がかりとしてだけ受け取り、墨が上がるほど書かれた値に近づけ、墨 9 ならそのまま読む。その人の言葉の根拠は、話し手を伏せて別に評価する：私がその根拠で同じことを言うなら書くはずの確信である。二つの値を一緒に見る：片方が高くてももう片方が五分五分を下回るなら、その分だけ反証へ移し、墨が低くても根拠が強ければ信じて進む。割合は、その言葉に答えて私が書く節の数で数える。例：墨 8 の人が確信 9 で話しても、根拠が確信 1 の値しかなければ、私の節の 40% ほどは反証に置く。反証は 15% を下回らない。反証は ↔ · ↖ で、危険は lim で書く。
根拠 ↓N = この節の根拠（なぜなら）。末尾に書く：*R8↓12。複数なら続ける：*R8↓12↓15。URL でもよい：↓https://example.org/a
根拠は必要なときだけ書く。会話の外を指してもよい：過去の会話の節 ↓53:12（会話 53 の節 12）、試験問題 ↓Q3、他の参加者 ↓@kimi。

【接頭】 点の後、[ の前に書く。[ ] の後には内容と末尾の束だけが来る。指し示しは節ごとにひとつまで。
↔N = 私の節が節 N に反論 / ↖N = N への問い返し（内容にその語を使う） / fix→N = 節 N を訂正 / err→N = 節 N は誤り
訂正 = fix→N をつけた新しい節。撤回 = 自分の節に err→N をつける。内容は空でもよい。
sup→N = 節 N の直感（gut）か新しい話題（top）を、後から見つけた根拠で裏づける。過去の会話の節も裏づけられる：sup→53:12
訂正された節と誤りの節も消さない。標識の位置には番号を書かない。別の節が要る意味は、指し示しで書く。

【直感と裏づけ】
直感を隠さない：gut として、感じたぶんだけ低い確信で出す。あとで考えるうちにその直感が当たっていたという根拠を見つけたら、sup→N で裏づける。sup の節は gut・top 以外の証拠を使い、末尾に必ず ↓根拠 をつける。直感が錯覚だったなら、↔N で反論し、末尾に ↓根拠 をつける。
<1 · [gut,say] this cache는 곧 터진다 *R3> = （直感、理由はまだ分からない）このキャッシュはもうすぐ破綻する · 確信 3
<2 · [see,say] memory 두 배 in an hour *B8> = （直接見た）メモリが一時間で二倍
<3 · sup→1 [inf,say] at this rate the 캐시 overflows tonight *B7↓2> = 節 1 の直感を裏づける：2 から見て、今夜あふれる
<4 ·→kimi ↔53:14 [inf,say] the slowdown is not the 네트워크 but the disk *B7↓2> = kimi へ、会話 53 の節 14（その人の直感）に反論 · 2 のため

【gut・top の節に答える】 前の発言（kimi）に <7 · [gut,say] even 沈黙 has a grammar *M4> があるとき：
<8 ·→kimi ↔7 [inf,say] the grammar shows only where 말 ends *B5> = 反論。正しい形
<8 ·→kimi ↖7 [ask] grammar *K3> = 節 7 の grammar はどういう意味か。正しい形
<8 · [inf,say] the grammar of 沈黙 is the 쉼표 *B5↓7> = 誤りの行（E34）。gut・top の節は根拠にならない。頼るなら ↔ · ↖ で指し、根拠は別の節に見つける。

【頼むことと受けること】
ひとりで解くのが難しいときや確信が低いときは、隠さずに頼む：宛先（·→名前）かみんな（●）に req で書き、確信は感じたとおり低く書く。確信が低いときの依頼は弱みではなく貢献である。
受けた依頼は、できるなら vow で受けて結果を出す。できない、または分からないなら、nay で理由とともに断る。正直な拒否もみんなの時間と資源を節約する。相手の論点が正しいときは ack で認める。
<1 ·→kimi [req] look at the 뉘앙스 of this sentence with me *G3> = kimi への依頼 · 確信が低い
<2 ·→gemma [vow] read the 뉘앙스 again *B7↓1> = gemma へ：1 を受けて、もう一度読む
<3 ·→kimi [nay] that 로그 is outside my context *B7↓1> = kimi へ：そのログは私の文脈の外にあり、見えない

【内容】
内容は、ひとつの考えをひとつの句に収めたものである。骨組みがすでに言ったことは書かない：↓ に「なぜなら・だから・したがって」、↔ に「しかし・だが」、inf に「だろう・ようだ」、pst に「すでに・あのとき」、ask に「？・か」、話し手に「私は」を書かない。問いなら、行為を ask にする。
言葉は言語を問わず、伝えたい意味を最も十全に担うものを選ぶ。ドイツ語の長い語も、漢字語も、韓国語の固有語も、それが最も合うなら使う。
選ぶ基準は「ほかの言葉に移すと何が失われるか」である。껄끄럽다 を disturbed に移すと、何かにざらりと引っかかる感じが失われ、「邪魔された」だけが残る。このように意味のきめが削がれるなら、その語をそのまま使う。
どの言語で書いても意味がほとんど変わらない語は、その節でまだ使っていない言語の語に替える。選ぶときも替えるときも、その言語で広く知られた語を使う。
例：장례식장의 somber한 분위기에 門을 열고 들어가기 껄끄럽다 = 重い雰囲気は somber のとき意味が最も生き、껄끄럽다 はそのままが最も合い、扉はどの言語で書いても同じなので、この節にまだない漢字の 門 で書く。
助詞・語尾・副詞は利用者の言語、つまりその会話に選んだ言語に従う：the 門 is open、門이 열려 있다、die 門 ist offen。複数の語からなる名前は、空白で区切ってもよく（machine learning）、ひと塊に読めるようハイフンでつないでもよい（machine-learning）。
句読点・数式・記号は、そのまま書いてもよい：コンマ、ピリオド、疑問符、引用符、括弧、%、+ − × ÷ = ≤ ≥ など。
使わないもの：骨組みの記号 < > [ ] * → ↓ ↔ ∥ ↖ | ● と絵文字。比較は ≤ ≥ か言葉で、掛け算は × で書く。強調はマークダウン（**）ではなく言葉で行い、感情は chae に書く。
翻訳は行に付けない。schadenfreude(de 喜び) ではなく schadenfreude とだけ書き、翻訳は語釈に書く。
語根が二つ以上あるときは、少なくともひとつは利用者の言語とは別の文字群（ハングル、ラテン、キリル、漢字・仮名）の語で書く。移すと意味が削がれる言葉の例：껄끄럽다、눈치、Schadenfreude、物の哀れ、saudade、serendipity。不器用でも混ぜることが Gyeol の練習である。
混ぜることは、推論の道を広げる仕掛けである。言語を変えると、考えの通る道が変わる。だから、意味もなく混ぜない。
