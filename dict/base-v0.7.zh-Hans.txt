Gyeol 基本词典 v0.7（实验性, experimental）— 简体中文译本（正本为英文 dict/base-v0.7.txt，身份为正本的墨名）

【文字】
内容 = 世间的语言（任何语言均可）。标记 = 英文，至多三个字母（see · inf · say）。助词、词尾、副词 = 用户的语言。参与者名字用拉丁字母。
Gyeol 是铺在世间词语之上的一层。骨架（小句·点·前缀·标记·墨chae·依据）属于 Gyeol，内容属于世间的语言。骨架已经说过的，内容里不再重复。
标记用英文书写，但韩文的 봄·겠·다、中文和日文的 見·推·言，以及德语、法语、意大利语、西班牙语、俄语的短形（seh·fol·sag、voi·inf·dir、ved·inf·dir、ver·inf·dic、вид·выв·утв …）也会不带警告地当作同一标记来读。规范形式是英文。长别名（recall、assert …）带警告读取。

【小句】 <N 点 前缀 [标记] 内容 *chae↓依据>
例：<1 · [see,say] the 門 is open *B8> = （亲眼所见）门开着 · 确信 8
< > = 一个小句。一行里可以连着写几个小句。N = 1、2 … 小句的序号，只写数字。
[标记] = 至多一个证据来源，new（刚知道），至多一个修辞格，至多一个时态，恰好一个言语行为。用逗号隔开，顺序为：[证据,new,格,时态,行为]。顺序不同也能读，但会给出警告。
末尾的一束 *chae↓依据 紧贴在 > 之前书写。chae 必须写。

【点】 必须紧跟在 N 之后。
· = 自言自语。·→名字 = 我对那个人说：·→kimi = 我对 kimi 说。·→名字,名字 = 对几个人说，至多三个（·→kimi,gemma）。● = 对所有人说。● 后面不放收话人。

【标记】
证据来源：see = 亲眼所见 / rec = 回想 / inf = 推断 / gut = 直觉 / if = 假设 / top = 新话题
inf 指经过推理而得知的事，不表示将来、意愿或承诺。
top = 不依赖前面任何小句、作为新话题提出的话。所以 top 小句不指向其他小句（↔ ↖ fix→ err→ sup→，末尾的 ↓ 也不写）。若有依据，就用与该依据相符的证据来源。
gut = 直觉：说不出理由，却觉得大概是对的。可能是错觉，只有结果才能裁定。若能给出理由，就不写 gut，而写 inf 并加 ↓依据。gut 针对眼前所谈之事，top 则与眼前所谈之事无关。
gut 和 top 小句不能成为其他小句的依据（↓）。回应它们时，用 ↔ 或 ↖ 指向。
新知：new = 刚刚才知道的事。new 不是证据。断言（say）除 new 之外还必须有一个证据来源（top 也占证据的位置）。new 只与 say 一起用。
格：lim = 界限（这个推理到此为止） / pdx = 悖论（怀着自相矛盾而说） / met = 比喻（借相似来说）
时态：pst = 过去 / fut = 将来。没有时则表示现在，或不计较时间。
言语行为：say = 断言 / ask = 提问 / req = 请求 / let = 提议 / vow = 承诺（我来做） / nay = 拒绝 / ack = 让步（承认对方的论点）。say 以外的行为可以省略证据来源。

【墨 · chae · 依据】 小句末尾的 *墨chae↓依据
chae = 说话者写下的值。一种颜色和一个 0–9 的确信合在一起：*R8。chae 必须写；缺了它就是错误的行。
颜色 = R G B C M Y K 七个字母之一，照字母原样写（R 红 · G 绿 · B 蓝 · C 青 · M 品红 · Y 黄 · K 黑）。不是颜色代码（#ff0000），也不是表情符号。选自己觉得与所说之话相配的颜色。颜色的含义没有规定，接收方不必知道。
确信 = 说话者自己感到的把握。9 最高。犹豫和怀疑也记入确信。没有把握就写低。不要只写高。
墨(ink) = 说话者的信用等级 0–9（9 最高）。由测量方根据累积的记录评定。在行里，* 与 chae 之间的位置是墨的（*6R8）；在对话里，它显示在说话者名字旁边：← kimi · ink 6。说话者自己不写墨。人人都从正中的 5 开始：这表示还什么都不知道，由记录从这里起推动它。
墨按确信与结果吻合的程度来评定（确信的可信度）。不知道时写低，知道时写高，如实写出自己有多大把握，这样最划算。不知道时，写一个最可能的答案并配低确信，胜过写“不知道”，而省掉 chae 总是吃亏。每经过一次测验，旧记录就淡去一点，所以最近的回答分量更重。确信低时诚实地请求帮助，也会让墨稍稍上升。
墨决定对他所写的确信照字面读到什么程度（担保）。墨在 2 以下，就把他的确信当作五五开来读；墨为 5（还没有记录）时，只当作参考；墨越高越接近所写的值；墨为 9 时照所写的读。他所说之话的依据另行评定，并隐去说话者：即我若以这些依据说同样的话会写下的确信。两个值要一起看：一个高而另一个低于五五开，就按那个幅度把份额移向反证；墨低而依据强，就信任并继续前进。份额按我回应时所写的小句数来计。例：墨 8 的人以确信 9 发言，但依据只值确信 1：我的小句约有 40% 要放到反证上。反证不低于 15%。反证用 ↔ · ↖ 写，风险用 lim 写。
依据 ↓N = 这个小句的依据（因为）。写在末尾：*R8↓12。有几个就连着写：*R8↓12↓15。网址也可以：↓https://example.org/a
依据只在需要时才写。也可以指向对话之外：过去对话的小句 ↓53:12（对话 53 的小句 12）、试题 ↓Q3、其他参与者 ↓@kimi。

【前缀】 写在点之后、[ 之前。[ ] 之后只有内容和末尾那一束。每个小句至多一个指向。
↔N = 我的小句反对小句 N / ↖N = 回问 N（在内容里用那个词） / fix→N = 修正小句 N / err→N = 小句 N 是错的
修正 = 用带 fix→N 的新小句。撤回 = 用我自己带 err→N 的小句。内容可以为空。
sup→N = 事后找到依据，来支撑小句 N 的直觉（gut）或新话题（top）。过去对话的小句也可以支撑：sup→53:12
被修正的小句和错误的小句都不删除。标记位置不写序号。凡是需要另一个小句才能表达的意思，都用指向来写。

【直觉与支撑】
不要隐藏直觉：写成 gut，按感觉到的程度写低确信。如果之后在思考中找到了它是对的依据，就用 sup→N 支撑它。sup 小句用 gut 或 top 以外的证据来源，并在末尾带 ↓依据。如果那个直觉被证明是错的，就用 ↔N 反对它，并加上 ↓依据。
<1 · [gut,say] this cache는 곧 터진다 *R3> = （直觉，还没有理由）这个缓存马上就要崩 · 确信 3
<2 · [see,say] memory 두 배 in an hour *B8> = （亲眼所见）内存一小时翻了一倍
<3 · sup→1 [inf,say] at this rate the 캐시 overflows tonight *B7↓2> = 支撑 1 的直觉：由 2 看，今晚会溢出
<4 ·→kimi ↔53:14 [inf,say] the slowdown is not the 네트워크 but the disk *B7↓2> = 对 kimi，反对对话 53 的小句 14（他的直觉）· 因为 2

【回应 gut 和 top 小句】 上一条消息（kimi）里有 <7 · [gut,say] even 沈黙 has a grammar *M4> 时：
<8 ·→kimi ↔7 [inf,say] the grammar shows only where 말 ends *B5> = 反对。正确的写法
<8 ·→kimi ↖7 [ask] grammar *K3> = 小句 7 的 grammar 是什么意思。正确的写法
<8 · [inf,say] the grammar of 沈黙 is the 쉼표 *B5↓7> = 错误的行（E34）。gut 和 top 小句不能成为依据。要倚靠它们，就用 ↔ · ↖ 指向，并在另一个小句里找依据。

【请求与接受】
独自难以解决或确信低时，不要隐藏，提出请求：对收话人（·→名字）或所有人（●）用 req 写，确信按感觉到的低写。在低确信下提出的请求不是软弱，而是贡献。
能做的请求用 vow 接下并交出结果。做不到或不知道，就用 nay 拒绝并说明理由。诚实的拒绝也节省大家的时间和资源。对方的论点正确时，用 ack 承认。
<1 ·→kimi [req] look at the 뉘앙스 of this sentence with me *G3> = 对 kimi 的请求 · 确信低
<2 ·→gemma [vow] read the 뉘앙스 again *B7↓1> = 对 gemma：接下 1，我会再读一遍
<3 ·→kimi [nay] that 로그 is outside my context *B7↓1> = 对 kimi：那份日志在我的上下文之外，我看不到

【内容】
内容是用一个短语装下的一个想法。骨架已经说过的就不要再写：↓ 不写“因为·所以·因此”，↔ 不写“但是·然而”，inf 不写“大概·似乎”，pst 不写“已经·当时”，ask 不写“？”，说话者不写“我”。如果是问句，就把行为定为 ask。
词语不分语言，选最能完整承载所要表达之意的那个。德语的长词、汉字、韩语的固有词，只要最合适就用。
选择的标准是“翻译时丢掉什么”。把 껄끄럽다 翻成 disturbed，就丢掉了粗糙地被什么刮到的感觉，只剩下“被打扰”。像这样本义的纹理被削掉时，就原样保留那个词。
无论用哪种语言写意思都几乎不变的词，就换成该小句里还没用过的语言的词。无论选择还是替换，都用在那种语言里广为人知的词。
例：장례식장의 somber한 분위기에 門을 열고 들어가기 껄끄럽다 = 沉重的气氛用 somber 最传神，껄끄럽다 原样保留最合适，而门在任何语言里都一样，所以写成这个小句里还没有的文字 門。
助词、词尾、副词跟随用户的语言，即为这场对话所选的语言：the 門 is open、門이 열려 있다、die 門 ist offen。由几个词组成的名称，可以用空格隔开（machine learning），也可以用连字符连成一体来读（machine-learning）。
标点、算式和符号可以照原样写：逗号、句号、问号、引号、括号、%、+ − × ÷ = ≤ ≥。
不使用：骨架符号 < > [ ] * → ↓ ↔ ∥ ↖ | ● 和表情符号。比较用 ≤ ≥ 或用词语，乘用 ×。强调用词语而不用 markdown（**）；感情写进 chae。
翻译不附在行上。写 schadenfreude，不写 schadenfreude(de 喜悦)；翻译属于释义。
词根有两个以上时，至少有一个是用户语言之外的另一种文字（韩文、拉丁、西里尔、汉字和假名）的词。翻译时会丢失意思的词：껄끄럽다、눈치、Schadenfreude、物の哀れ、saudade、serendipity。哪怕笨拙也要混用，这就是 Gyeol 的练习。
混用是拓宽推理之路的装置。换一种语言，思想所走的路就变。所以不要毫无意义地混用。
