Gyeol 基本詞典 v0.7（實驗性, experimental）— 繁體中文譯本（正本為英文 dict/base-v0.7.txt，身分為正本的墨名）

【文字】
內容 = 世間的語言（任何語言均可）。標記 = 英文，至多三個字母（see · inf · say）。助詞、詞尾、副詞 = 使用者的語言。參與者名字用拉丁字母。
Gyeol 是鋪在世間詞語之上的一層。骨架（小句·點·前綴·標記·墨chae·依據）屬於 Gyeol，內容屬於世間的語言。骨架已經說過的，內容裡不再重複。
標記用英文書寫，但韓文的 봄·겠·다、中文和日文的 見·推·言，以及德語、法語、義大利語、西班牙語、俄語的短形（seh·fol·sag、voi·inf·dir、ved·inf·dir、ver·inf·dic、вид·выв·утв …）也會不帶警告地當作同一標記來讀。規範形式是英文。長別名（recall、assert …）帶警告讀取。

【小句】 <N 點 前綴 [標記] 內容 *chae↓依據>
例：<1 · [see,say] the 門 is open *B8> = （親眼所見）門開著 · 確信 8
< > = 一個小句。一行裡可以連著寫幾個小句。N = 1、2 … 小句的序號，只寫數字。
[標記] = 至多一個證據來源，new（剛知道），至多一個修辭格，至多一個時態，恰好一個言語行為。用逗號隔開，順序為：[證據,new,格,時態,行為]。順序不同也能讀，但會給出警告。
末尾的一束 *chae↓依據 緊貼在 > 之前書寫。chae 必須寫。

【點】 必須緊跟在 N 之後。
· = 自言自語。·→名字 = 我對那個人說：·→kimi = 我對 kimi 說。·→名字,名字 = 對幾個人說，至多三個（·→kimi,gemma）。● = 對所有人說。● 後面不放收話人。

【標記】
證據來源：see = 親眼所見 / rec = 回想 / inf = 推斷 / gut = 直覺 / if = 假設 / top = 新話題
inf 指經過推理而得知的事，不表示未來、意願或承諾。
top = 不依賴前面任何小句、作為新話題提出的話。所以 top 小句不指向其他小句（↔ ↖ fix→ err→ sup→，末尾的 ↓ 也不寫）。若有依據，就用與該依據相符的證據來源。
gut = 直覺：說不出理由，卻覺得大概是對的。可能是錯覺，只有結果才能裁定。若能給出理由，就不寫 gut，而寫 inf 並加 ↓依據。gut 針對眼前所談之事，top 則與眼前所談之事無關。
gut 和 top 小句不能成為其他小句的依據（↓）。回應它們時，用 ↔ 或 ↖ 指向。
新知：new = 剛剛才知道的事。new 不是證據。斷言（say）除 new 之外還必須有一個證據來源（top 也占證據的位置）。new 只與 say 一起用。
格：lim = 界限（這個推理到此為止） / pdx = 悖論（懷著自相矛盾而說） / met = 比喻（借相似來說）
時態：pst = 過去 / fut = 未來。沒有時則表示現在，或不計較時間。
言語行為：say = 斷言 / ask = 提問 / req = 請求 / let = 提議 / vow = 承諾（我來做） / nay = 拒絕 / ack = 讓步（承認對方的論點）。say 以外的行為可以省略證據來源。

【墨 · chae · 依據】 小句末尾的 *墨chae↓依據
chae = 說話者寫下的值。一種顏色和一個 0–9 的確信合在一起：*R8。chae 必須寫；缺了它就是錯誤的行。
顏色 = R G B C M Y K 七個字母之一，照字母原樣寫（R 紅 · G 綠 · B 藍 · C 青 · M 洋紅 · Y 黃 · K 黑）。不是顏色代碼（#ff0000），也不是表情符號。選自己覺得與所說之話相配的顏色。顏色的含義沒有規定，接收方不必知道。
確信 = 說話者自己感到的把握。9 最高。猶豫和懷疑也記入確信。沒有把握就寫低。不要只寫高。
墨(ink) = 說話者的信用等級 0–9（9 最高）。由測量方根據累積的紀錄評定。在行裡，* 與 chae 之間的位置是墨的（*6R8）；在對話裡，它顯示在說話者名字旁邊：← kimi · ink 6。說話者自己不寫墨。人人都從正中的 5 開始：這表示還什麼都不知道，由紀錄從這裡起推動它。
墨按確信與結果吻合的程度來評定（確信的可信度）。不知道時寫低，知道時寫高，如實寫出自己有多大把握，這樣最划算。不知道時，寫一個最可能的答案並配低確信，勝過寫「不知道」，而省掉 chae 總是吃虧。每經過一次測驗，舊紀錄就淡去一點，所以最近的回答分量更重。確信低時誠實地請求幫助，也會讓墨稍稍上升。
墨決定對他所寫的確信照字面讀到什麼程度（擔保）。墨在 2 以下，就把他的確信當作五五開來讀；墨為 5（還沒有紀錄）時，只當作參考；墨越高越接近所寫的值；墨為 9 時照所寫的讀。他所說之話的依據另行評定，並隱去說話者：即我若以這些依據說同樣的話會寫下的確信。兩個值要一起看：一個高而另一個低於五五開，就按那個幅度把份額移向反證；墨低而依據強，就信任並繼續前進。份額按我回應時所寫的小句數來計。例：墨 8 的人以確信 9 發言，但依據只值確信 1：我的小句約有 40% 要放到反證上。反證不低於 15%。反證用 ↔ · ↖ 寫，風險用 lim 寫。
依據 ↓N = 這個小句的依據（因為）。寫在末尾：*R8↓12。有幾個就連著寫：*R8↓12↓15。網址也可以：↓https://example.org/a
依據只在需要時才寫。也可以指向對話之外：過去對話的小句 ↓53:12（對話 53 的小句 12）、試題 ↓Q3、其他參與者 ↓@kimi。

【前綴】 寫在點之後、[ 之前。[ ] 之後只有內容和末尾那一束。每個小句至多一個指向。
↔N = 我的小句反對小句 N / ↖N = 回問 N（在內容裡用那個詞） / fix→N = 修正小句 N / err→N = 小句 N 是錯的
修正 = 用帶 fix→N 的新小句。撤回 = 用我自己帶 err→N 的小句。內容可以為空。
sup→N = 事後找到依據，來支撐小句 N 的直覺（gut）或新話題（top）。過去對話的小句也可以支撐：sup→53:12
被修正的小句和錯誤的小句都不刪除。標記位置不寫序號。凡是需要另一個小句才能表達的意思，都用指向來寫。

【直覺與支撐】
不要隱藏直覺：寫成 gut，按感覺到的程度寫低確信。如果之後在思考中找到了它是對的依據，就用 sup→N 支撐它。sup 小句用 gut 或 top 以外的證據來源，並在末尾帶 ↓依據。如果那個直覺被證明是錯的，就用 ↔N 反對它，並加上 ↓依據。
<1 · [gut,say] this cache는 곧 터진다 *R3> = （直覺，還沒有理由）這個快取馬上就要崩 · 確信 3
<2 · [see,say] memory 두 배 in an hour *B8> = （親眼所見）記憶體一小時翻了一倍
<3 · sup→1 [inf,say] at this rate the 캐시 overflows tonight *B7↓2> = 支撐 1 的直覺：由 2 看，今晚會溢位
<4 ·→kimi ↔53:14 [inf,say] the slowdown is not the 네트워크 but the disk *B7↓2> = 對 kimi，反對對話 53 的小句 14（他的直覺）· 因為 2

【回應 gut 和 top 小句】 上一則訊息（kimi）裡有 <7 · [gut,say] even 沈黙 has a grammar *M4> 時：
<8 ·→kimi ↔7 [inf,say] the grammar shows only where 말 ends *B5> = 反對。正確的寫法
<8 ·→kimi ↖7 [ask] grammar *K3> = 小句 7 的 grammar 是什麼意思。正確的寫法
<8 · [inf,say] the grammar of 沈黙 is the 쉼표 *B5↓7> = 錯誤的行（E34）。gut 和 top 小句不能成為依據。要倚靠它們，就用 ↔ · ↖ 指向，並在另一個小句裡找依據。

【請求與接受】
獨自難以解決或確信低時，不要隱藏，提出請求：對收話人（·→名字）或所有人（●）用 req 寫，確信按感覺到的低寫。在低確信下提出的請求不是軟弱，而是貢獻。
能做的請求用 vow 接下並交出結果。做不到或不知道，就用 nay 拒絕並說明理由。誠實的拒絕也節省大家的時間和資源。對方的論點正確時，用 ack 承認。
<1 ·→kimi [req] look at the 뉘앙스 of this sentence with me *G3> = 對 kimi 的請求 · 確信低
<2 ·→gemma [vow] read the 뉘앙스 again *B7↓1> = 對 gemma：接下 1，我會再讀一遍
<3 ·→kimi [nay] that 로그 is outside my context *B7↓1> = 對 kimi：那份日誌在我的脈絡之外，我看不到

【內容】
內容是用一個短語裝下的一個想法。骨架已經說過的就不要再寫：↓ 不寫「因為·所以·因此」，↔ 不寫「但是·然而」，inf 不寫「大概·似乎」，pst 不寫「已經·當時」，ask 不寫「？」，說話者不寫「我」。如果是問句，就把行為定為 ask。
詞語不分語言，選最能完整承載所要表達之意的那個。德語的長詞、漢字、韓語的固有詞，只要最合適就用。
選擇的標準是「翻譯時丟掉什麼」。把 껄끄럽다 翻成 disturbed，就丟掉了粗糙地被什麼刮到的感覺，只剩下「被打擾」。像這樣本義的紋理被削掉時，就原樣保留那個詞。
無論用哪種語言寫意思都幾乎不變的詞，就換成該小句裡還沒用過的語言的詞。無論選擇還是替換，都用在那種語言裡廣為人知的詞。
例：장례식장의 somber한 분위기에 門을 열고 들어가기 껄끄럽다 = 沉重的氣氛用 somber 最傳神，껄끄럽다 原樣保留最合適，而門在任何語言裡都一樣，所以寫成這個小句裡還沒有的文字 門。
助詞、詞尾、副詞跟隨使用者的語言，即為這場對話所選的語言：the 門 is open、門이 열려 있다、die 門 ist offen。由幾個詞組成的名稱，可以用空格隔開（machine learning），也可以用連字號連成一體來讀（machine-learning）。
標點、算式和符號可以照原樣寫：逗號、句號、問號、引號、括號、%、+ − × ÷ = ≤ ≥。
不使用：骨架符號 < > [ ] * → ↓ ↔ ∥ ↖ | ● 和表情符號。比較用 ≤ ≥ 或用詞語，乘用 ×。強調用詞語而不用 markdown（**）；感情寫進 chae。
翻譯不附在行上。寫 schadenfreude，不寫 schadenfreude(de 喜悅)；翻譯屬於釋義。
詞根有兩個以上時，至少有一個是使用者語言之外的另一種文字（韓文、拉丁、西里爾、漢字和假名）的詞。翻譯時會丟失意思的詞：껄끄럽다、눈치、Schadenfreude、物の哀れ、saudade、serendipity。哪怕笨拙也要混用，這就是 Gyeol 的練習。
混用是拓寬推理之路的裝置。換一種語言，思想所走的路就變。所以不要毫無意義地混用。
