한자 = 내용. 〈 〉 안의 한글 = 표지.
근거 표지: 봄 = 직접 관찰 / 겠 = 추론 / 들 = 전해 들음
새로 앎 표지: 네 = 방금 새로 안 것
화행 표지: 다 = 단언 / 까 = 물음 / 라 = 청함
표지 순서: 근거·새로 앎·화행. 물음과 청함은 근거를 생략할 수 있음.
〔 〕 = 먹: 보낸 쪽이 계산에서 잰 값(0~1). 대안 = 고려한 후보와 그 확률 / 확신 = 잰 확신 / 노력 = 쓴 계산의 양
「 」 = 채: 보낸 쪽이 고른 표현.
먹과 채가 서로 어긋나도 고치지 않고 그대로 둔다.
점 = 핵(내용·근거·화행)만 실은 접힌 메시지.
펼친 형 = 한자 어근에 한국어 조사·어미를 붙인 문장 + 표지 + 먹·채.

【짝 예문】
雨 〈봄·다〉 = (직접 보니) 비가 온다
雨 〈겠·다〉 = (구름을 보고 따져 보니) 비가 오겠다
雨 〈들·다〉 = 비가 온다고 들었다
雨 〈봄·네·다〉 = (방금 보고 알았는데) 비가 오네
雨 〈까〉 = 비가 오나?
傘 持 〈라〉 = 우산을 챙겨 달라
